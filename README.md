# EduSummerizer
EduSummerizer is an AI-powered education platform for smart learning. It provides content summarization, syllabus-based notes with diagrams, flowcharts, formulas and code, quizzes, assessments, and performance tracking. It includes Student, Faculty, and Admin dashboards, multilingual support, and an AI assistant for academic and platform guidance.
